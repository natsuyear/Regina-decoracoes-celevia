# Regina Decorações + Celevia by Regina

Protótipo de site para a Regina Decorações, que faz decoração de festas desde 1999 em Santo André e no Grande ABC, e para a sub-marca **Celevia by Regina**, de kits de festa pegue e monte.

Case de portfólio de **Nathália Nishimuta** (UX/UI e front-end).

## O que o site faz
- Mostra festas por tipo (casamento, chás, infantil, temáticas e aniversário), com filtro por cor e galeria.
- Tem um orçamento guiado que gera uma mensagem pronta para o WhatsApp.
- Tem a aba Celevia, com a paleta da marca, catálogo de kits, carrinho e checkout rápido.
- Disponibiliza uma foto do contrato para credibilidade.

## Tecnologias
HTML, CSS e JavaScript puros. É um site estático, sem build.

## Como publicar (GitHub Pages)
1. Suba todos os arquivos na raiz do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.

## Observações
- As fotos são ilustrativas e serão trocadas pelas fotos reais da Regina.
- Os preços e os dados de clientes são fictícios.
- Na versão publicada, o e-mail do contrato é aberto pelo `mailto`. O envio automático depende de um serviço externo, como o EmailJS.
